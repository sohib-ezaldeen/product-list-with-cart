# 🛒 QuickCart App

A modern and interactive shopping cart web application built using **HTML, CSS, and JavaScript**.
The app allows users to browse products, add/remove items from the cart, and enjoy a smooth user experience.

---

## 🚀 Live Demo

👉 https://quickcart-app-site.netlify.app/

---

## 📌 Features

* 🛍️ Browse products dynamically
* ➕ Add products to cart
* ➖ Remove products from cart
* 🔄 Real-time cart updates
* 🎯 Smooth scrolling for better UX
* ⚡ Fast and responsive design
